## 规模验收

在本机生产服务 `node server/index.mjs --serve`、内置 Chromium 浏览器中真实完成下列流程。输入可用 `npm run fixtures:scale` 重建；生成文件的 SHA-256 与样本报告一致。

1. 通过文件选择器导入并确认 20,000 行报名、20,000 行签到、10,000 行反馈。
2. 设定全部到场者受邀，确认版本：20,000 报名、10,000 到场、50% 到场率、10,000 重复、0 未报名、100% 回收、均分 4。
3. 渠道分析：十组全部为 1,000/2,000=50%，图表、表格及事实文字一致。
4. 保存后刷新，确认版本与 20,000 报名指标恢复。
5. 实际导出完整备份及 HTML；备份包含全部源记录、版本与分析。
6. 实际将 HTML 打印成 A4 PDF，再通过 Poppler 将全部页面渲染为图片逐页检查。

报告初始出现 42 页交错行号附录，加入等间隔压缩后为 **6 页**；保留两端、间隔、数量和完整逐行 JSON 引用，不截断证据。六页均检查中文、表格、图表、长哈希、页边界，无乱码、遮挡或截断。分页仍可能随用户打印设置改变。

- [规模概览截图](screenshots/scale-overview.jpg)
- [实际打印 PDF 样本](samples/scale-report.pdf)

1366px 桌面六项指标可见，390px 窄屏备份窗口可操作。本机 Node 核心计算测试处理 50,000 行的观测值为 53.7、77.5 和 102.2 ms（不同次运行，会波动）；这不含文件读取、DOM、存储，不作为浏览器速度承诺。浏览器验证说明上述样本可完成全流程，不代表全部设备或全部数据形态的性能。
